Escáner Web de Archivos y Links

Un solo archivo HTML, sin instalar nada. Arrastra archivos (o carpetas) o pega URLs, y el navegador los analiza en tu máquina: tus archivos nunca salen de ella.

Cómo funciona

📄 Archivos

Calcula el SHA-256 local y lo compara con tus firmas (lista de hashes, sin internet) y/o con VirusTotal (API key gratuita; solo viaja el hash, nunca el archivo).

🔗 Links

Heurísticas locales sin clave (IPs directas, punycode, acortadores, TLDs de riesgo, credenciales en la URL) + VirusTotal + URLhaus (claves gratuitas, opcionales).

✅ Uso

Abre la página → arrastra archivos o pega URLs → (opcional) guarda tus API keys → revisa: ✅ limpio · ❓ sospechoso · 🦠 malicioso.

⚠️ Limitaciones

Solo escanea lo que tú le pegas (no el PC completo), archivos >1-2 GB pueden ser pesados, y VT/URLhaus necesitan internet.
