Escáner Web de Archivos y Links

Un solo archivo HTML, sin instalar nada. Arrastra archivos (o carpetas) o pega URLs, y el navegador los analiza en tu máquina: tus archivos nunca salen de ella.

Cómo funciona

📄 Archivos

Análisis local sin internet: tipo real (magic bytes), discrepancia extensión/tipo, entropía, secciones y APIs de PE, patrones de scripts, macros/DDE en Office, zip bomb y ejecutables anidados. Además calcula el SHA-256 y lo compara con tus firmas y/o VirusTotal (opcional).

🔗 Links

Heurísticas locales sin clave (IPs directas, punycode, acortadores, TLDs de riesgo, credenciales en la URL) + VirusTotal + URLhaus (claves gratuitas, opcionales).

📊 Qué significa cada resultado

  • ✅ Limpio / Sin señalesArchivos: sin firma tuya, sin señales locales y (si consultas VT) ningún motor lo marca. Links: ninguna heurística local se activó.
  • ⚠️ Firma conocidaArchivos: el hash está en tu lista de firmas, o sea, un archivo que tú registraste como peligroso.
  • 🦠 Malicioso / Señales localesAl menos un motor de VirusTotal lo marca, URLhaus lo tiene registrado, o el análisis local encontró señales fuertes (APIs de inyección, DDE, zip bomb, extensión falsificada…).
  • ❓ SospechosoArchivos: señales locales moderadas (empaquetado, alta entropía, macros, URLs embebidas raras) o motores de VT sospechosos. Links: se activaron señales locales.
  • No en VirusTotal / URLhausNo hay registro de ese hash o URL en la base. No significa que sea seguro: solo que nadie lo ha reportado.
  • Error / —No se pudo consultar (sin API key, sin internet o límite de peticiones). El "—" significa que esa consulta no está activada.

✅ Uso

Abre la página → arrastra archivos o pega URLs → (opcional) guarda tus API keys → revisa el resultado, que además tiñe la fila de verde, amarillo o rojo.

⚠️ Limitaciones

Solo escanea lo que tú le pegas (no el PC completo). Archivos muy grandes (>512 MB) se omiten. El análisis es estático (no ejecuta nada), así que un malware empaquetado y "limpio" puede pasar. VT y URLhaus necesitan internet.
